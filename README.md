# COMP662 — Generative Artificial Intelligence

Coursework repository for **COMP662 Generative Artificial Intelligence**, Lincoln University (NZ), Semester 2 2026.

This is not a software project — it's a working repo of weekly tutorial notebooks and study notes for the course, covering VAEs, GANs, Diffusion models, Transformers, LLMs, RAG, and Agentic AI.

## Structure

```
├── COMP662_S2_2026.md   # Course outline: weekly topics, assessment weights, due dates
├── TODO.md               # Running study TODO list
├── lecture/               # Lecture slides, one folder per week (lecture/weekN/)
└── tut/                   # Tutorial notebooks, one folder per week
    ├── week1/
    │   ├── tutorial1.ipynb
    │   └── data/
    │       ├── land_suitability.csv   # Binary classification dataset
    │       └── Weather_Data.csv       # Regression dataset
    └── week2/
        └── tutorial2-AE and VAE.ipynb
```

Each `tut/weekN/` folder contains that week's Jupyter notebook and, where needed, a `data/` subfolder with the CSVs it uses.

## Environment

- Python 3.13 virtualenv at `.venv/`
- Dependencies: torch, pandas, scikit-learn, matplotlib, ipykernel

Set up:

```bash
python3 -m venv .venv
.venv/bin/pip install torch pandas scikit-learn matplotlib ipykernel
```

Run a script:

```bash
.venv/bin/python <script.py>
```

Notebooks are edited in PyCharm and run cell-by-cell from the top (later cells depend on earlier variables). On Apple Silicon, the PyTorch device resolves to `mps`.
